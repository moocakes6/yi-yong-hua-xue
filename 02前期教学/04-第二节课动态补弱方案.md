# 第二节课动态补弱方案（110分钟）

本方案不预设学生的薄弱点。教师先填写`05-学生初中化学基础诊断记录表.md`，再选择内容。

## 课后判读

只看子题，不看整道大题的对错。

| 卷面表现 | 错误类型 | 初步掌握程度 |
|---|---|---|
| 子题正确，信心为“确定” | 无 | B，P0仍用变式确认后才能记A |
| 子题正确，信心为“猜测” | 不熟练 | B |
| 标“不会”，看到定义后能改正 | 知识遗忘 | C |
| 信心为“确定”，但原理错误 | 概念混淆 | D |
| 关系式正确，只错算术或单位 | 计算或单位错误 | C |
| 方法正确，但看错数据或答错问 | 审题错误 | B或C |
| 原题正确，变式错误 | 迁移困难 | C |
| 70分钟结束时尚未做到 | 时间不足 | U |
| 时间充足但空白 | 初步视为尚未掌握 | D，第二节第一问先确认 |

P0项目只有变式独立正确，才把B或C改记为A。一道原题正确不直接记A，一道原题错误也不直接认定整个知识领域为D。

## 选择本节内容

从记录表中筛选同时满足三项的内容：初步掌握程度为C或D、关联程度为高、优先级为P0。按下列顺序取前三项：

1. 化学式、化合价、离子符号。
2. 相对式量、质量分数、质量与体积。
3. 方程式、配平、质量守恒。
4. 分子、原子、质子数、离子形成。

P1即使为D，也不进入本节，除非P0不足三项且剩余时间超过20分钟。P2只记录，不讲解。

## 110分钟流程

| 时段 | 教师活动 | 学生活动 | 结束标准 |
|---|---|---|---|
| 0–10 | 反馈最多三个优先点，不评讲整卷 | 确认自己同意的优先点 | 形成本节任务单 |
| 10–30 | 第一个点：定位错误、讲原理、例题 | 完成一道变式 | 变式独立正确则停止 |
| 30–50 | 第二个点，方法同上 | 完成一道变式 | 同上 |
| 50–70 | 第三个点，方法同上 | 完成一道变式 | 同上 |
| 70–85 | 把三个变式中的错误再确认一次 | 重做自己错的变式 | 连续两次独立正确才改记A |
| 85–100 | 进入第1章“化学的研究对象”“化学与医学” | 说出化学研究的四项内容 | 不回头复习初中目录 |
| 100–110 | 用第1章目录标出后续P1出现的位置 | 记录自己的P1和P2 | 明确下次不再全面复习初中 |

某个优先点的原诊断为A或确认后的B，并且学生能口头说明理由时，该20分钟时段取消，时间直接并入第1章。

某个点讲到20分钟仍不能独立完成变式时，停止继续扩展。记录保持D，改到该知识点对应章节的前8分钟处理，不挤占本节其他内容。

## 变式题

这些题目只有在对应知识点被选中时才使用。

### 化学式与离子

原理：正负化合价总数相等；系数表示粒子个数，下标表示一个化学式内部的原子个数。

例题：铝显+3价、氧显－2价，写出Al₂O₃。

变式：3CO₂中有几个二氧化碳分子、几个碳原子、几个氧原子？再写出钙离子与氯离子形成的化学式。

通过标准：3个二氧化碳分子，共3个碳原子、6个氧原子；化学式为CaCl₂。

### 相对式量与质量分数

原理：相对式量由相对原子质量相加，不写g。质量分数的分母是溶液质量。

例题：CaCO₃的相对式量。40＋12＋16×3＝100。

变式：5 g NaCl溶于水，配成200 g溶液，求溶质质量分数。再判断“200 mL溶液是否一定是200 g”。

通过标准：2.5%，列式为5/200×100%；明确不能仅凭体积判断质量。

### 方程式与质量守恒

原理：方程式两边同种原子总数相等；参加反应的质量总和等于生成物质量总和。

例题：配平2H₂＋O₂＝2H₂O，并判断4 g氢气与32 g氧气生成36 g水。

变式：配平Mg＋O₂→MgO。已知6 g氢气完全燃烧，利用质量比4∶36求生成水的质量。

通过标准：2Mg＋O₂＝2MgO；生成水54 g。

### 分子、原子与离子

原理：化学变化中分子可分、原子不可再分；质子数决定元素，最外层电子影响离子所带电荷。

例题：用第7题钠原子示意图重讲一遍，要求学生自己说出三步。

变式：氯原子最外层有7个电子，反应中易得到几个电子，形成什么离子？

通过标准：得到1个电子，形成Cl⁻。

## 调整规则

| 诊断结果 | 本节安排 |
|---|---|
| 没有C或D级P0 | 用10分钟做一组抽查。其余100分钟进入第1章第1–2节，并只按需处理第3节 |
| 1个P0为C或D | 该点25分钟。其余时间进入第1章 |
| 2个P0为C或D | 两点各22分钟，检测10分钟，剩余时间进入第1章 |
| 3个及以上 | 只取排序前三个，每个20分钟 |
| P0已掌握，P1较弱 | 本节不展开P1，把它们写到第3、5、13章前 |
| 只有P2较弱 | 不复习，直接进入第1章 |

## 停止初中复习的标准

学生能独立完成三项，即开始系统学习教材：

- 写出一个由离子构成的化学式。
- 算出一个相对式量，并且不写g。
- 用“溶质质量 / 溶液质量”列出质量分数。

三项通过后，第1章第3节不再完整重讲，只处理仍为C或D的小点。

若110分钟结束仍有P0为D，本节最后15分钟仍然进入第1章第1节。未通过的那一个点只占下一次课的前8分钟，然后继续教材，不再增加一整节初中复习课。
