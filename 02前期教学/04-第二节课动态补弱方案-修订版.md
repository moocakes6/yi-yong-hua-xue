# 第二节课动态补弱方案（修订版）

第二节总时长110分钟。它只处理会挡住第1章起步的结果，不把所有重要知识点集中补完。

## 用哪些结果做决定

先按子题填写记录表。只把C或D列入候选，U和“时间不足”先口头确认，不直接开讲。

| 诊断结果 | 第二节是否讲解 | 若暂不讲解，放在哪里 |
|---|---|---|
| 第3、6题，或第7题第（3）问为C或D | 讲解化学式与离子符号 | 这是进入第1章化学式内容前要确认的项目 |
| 第1、2题为D | 只用不超过10分钟随第1章对应小节处理 | 不单独占一个补弱模块 |
| 第4、5、7题第（1）（2）问为C或D | 不在第二节展开 | 进入第2章前确认 |
| 第8题为C或D | 不在第二节展开 | 第1章讲反应方程式时确认 |
| 第9题为C或D | 不并入第4章前置，也不默认占用第二节 | 单独留在方程式定量计算处 |
| 第10–13题为C或D | 不在第二节展开 | 进入第4章前确认 |
| 第14、15题为C或D | 不在第二节展开 | 进入第5章前确认 |
| 第17题为C或D | 不在第二节展开 | 进入第3章前确认 |
| 第16题为C或D | 不在第二节展开 | 做教学大纲中的实验前确认 |
| 第18–22题为C或D | 不在第二节展开 | 按关联表在第3、5、7章遇到时处理 |
| 第1章前项目都是A或B | 取消补弱模块 | 直接进入第1章 |

第7题要拆开看：离子符号属于第1章前；质子数和电子层属于第2章前。

## 110分钟安排

### 化学式与离子需要补

| 时段 | 内容 |
|---|---|
| 0–8 | 只反馈第3、6、7（3）题的错误类型 |
| 8–30 | 讲系数、下标、化合价代数和与离子符号 |
| 30–45 | 例题：由Al³⁺和O²⁻写出Al₂O₃ |
| 45–60 | 独立变式：判断3CO₂的分子数和原子数，写出CaCl₂ |
| 60–70 | 变式讲评。连续写对则停止，不追加同类题 |
| 70–100 | 进入第1章第一节、第二节 |
| 100–110 | 在目录上标出第2、3、4、5章前仍需确认的题号 |

变式通过标准：3个二氧化碳分子，共3个碳原子、6个氧原子；化学式为CaCl₂。

20分钟后仍不能独立完成时停止。该项保持D，下次课只用前8分钟再试一次，然后继续第1章。

### 化学式与离子已经掌握

| 时段 | 内容 |
|---|---|
| 0–10 | 用两道口头题复核化学式，不做新的初中专题 |
| 10–100 | 进入第1章第一节至第三节。第三节只处理学生实际错出的分类、变化或方程式问题 |
| 100–110 | 登记延后项目和对应章节 |

第2、4、5章前的内容即使重要性高，也不得因为本节有空余就提前整段复习。空余时间用于第1章正文。

## 各阶段只确认什么

- 第1章前：化学式、化合价和离子符号。
- 第2章前：分子与原子、质子数、电子层和离子形成过程。
- 第3章前：金属活动性顺序，以及氧气、二氧化碳的相关性质。
- 第4章前：相对式量、溶液、质量分数、质量与体积。不把质量守恒列为这里的门槛。
- 第5章前：pH方向、酸和指示剂、盐与酸的反应。
- 实验前：浓硫酸稀释、闻气体和酒精灯操作。
- 方程式计算处：配平与质量守恒分开检查。质量守恒错误不解释成第4章全部计算都不能学。

## 停止补弱

学生能读出2H₂O，并能按给定化合价写出一个化学式后，第二节的补弱结束。相对式量、质量分数、原子结构和pH不作为进入第1章的附加门槛。
