职校《医用化学》家教备课资料，供助手读取后辅助备课与讲课。本仓库为公开仓库。

## 目录

- `02前期教学/`：入学诊断方案、初中化学与医用化学关联表、诊断试卷与记录表（空白模板）
- `03第一课课件/`：第一课授课安排、核心知识复习课件（HTML / PDF / PPTX）及质量检查
- `可能的试题/试题来源与可信度说明.md`：网络试题的来源与使用限制说明

## 隐私

- 学生等个人姓名若出现，已替换为「小明」。当前收录的诊断表均为未填写的空白模板。
- 课件中出现的老师姓名按作者要求保留，未作替换。
