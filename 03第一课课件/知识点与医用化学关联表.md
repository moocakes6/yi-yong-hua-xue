# 初中知识与《医用化学（第2版）》关联

课件只有第1–12章。实验“基本操作、粗盐提纯、溶液配制”来自教学大纲，不是第13份课件。标有“课标补充”的内容不在现有课件中单列。

| 初中模块 | 课件或大纲中的位置 | 关系 |
|---|---|---|
| 变化与分类 | 第1章第三节；第3章具体化合物；第5章电解质 | 第1章直接复习。电解质是新内容 |
| 分子、原子、离子 | 第2章原子构成、电子排布、周期表 | 今天只打基础。同位素和递变规律是新课 |
| 化学用语 | 第1章化学式和化合价；第4章化学式量 | 化学式正确后，第4章才把数值写成 g/mol |
| 质量守恒与方程式 | 第1章定律和反应类型；后续各章写反应 | 守恒不作为第4章浓度计算的前置 |
| 相对式量与方程式计算 | 第4章摩尔质量、n＝m/M | 摩尔和物质的量是第4章新内容 |
| 溶液和质量分数 | 第4章第二节四种浓度；大纲中的溶液配制 | 质量浓度、物质的量浓度和渗透压留到第4章 |
| 酸碱盐与pH | 第1章定性回顾；第5章pH、盐和缓冲 | 今天只判断酸碱性，不做pH计算 |
| 空气、氧气、二氧化碳、水 | 第3章氧、硫、氮及化合物 | 检验现象和体积比服务第3章 |
| 金属活动性 | 第1章回顾；第3章钠、钙、铝、铁、锌 | 镁不在第3章的独立核心节中 |
| 实验安全 | 教学大纲实验单元 | 气体制取是课标补充，大纲未列气体制取 |
| 燃烧、化肥、材料、环境 | 第3章散点；第7章可燃性 | 课标补充，不提前系统教学 |
